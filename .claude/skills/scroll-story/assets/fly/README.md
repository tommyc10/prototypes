# Fly reference build

A complete bundled scroll-story reference. Copy this folder into the target project, install
its dependencies, and use the project's dev command and server settings. For a standalone
copy, run `npm install` and `npm run dev`, then open the URL printed at startup.
Run `npm run build` for the production check.

Adapt the copy, styles, scenes and timeline for the target product. Set `DASHBOARD_URL` to
its real dashboard destination; `/dashboard` is a placeholder route.
